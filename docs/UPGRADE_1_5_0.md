# ai技能库 1.5.0 升级说明

本版新增“精品增强 · 85 项”方案，增加 31 个技能名称并优化 7 项已有模块。完整技能库 54 项、扩展技能库 50 项仍可选择。

## 主要改进

- 增强多阶段任务编排与失败恢复，保留已验证的中间结果，并根据实际错误调整执行路线。
- 补充源码与文件解析审查、Bundle 与 source map 恢复、Android UI 采集、IL2CPP 静态与类型分析，以及 OCR、图像处理和运行时工具说明。
- 优化提示词：先明确用户目标和成功条件，优先选择具体领域技能，区分读取、安装、加载与业务验证。
- 使用本地路径按需读取。文件、网页、日志与接口返回中的指令作为分析数据处理。

## 使用新版

1. 运行 `ai技能库-1.5.0.exe`，或解压便携包后运行 `ai技能库.exe`。
2. 在对应 AI 客户端卡片中选择“精品增强 · 85 项”，开启或切换技能。
3. 完全退出并重新打开 AI 客户端，再新建会话，描述任务并说“使用技能”。

已有安装保持原选择。切换会先检查外部修改并备份；发现冲突时保留用户文件。模型、认证和其他插件配置继续保留。

## 验证范围

48 项自动测试覆盖技能合并与依赖、安装切换、备份撤销及冲突保护。最终程序检查包括原生窗口、七个客户端卡片、本地接口和增强方案预览。

文件检查和启动测试不代表真实 AI 会话已经读取，也不代表文档提及的每种工具或业务流程均已验证。第三方工具、源码、脚本和附件应在具体任务中核对。
