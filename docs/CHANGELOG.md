# 更新记录

## 1.4.2 · 2026-10-10

- 修复 `observe_native_calls` 的裸类型名称正则：用明确的十六进制方括号字面量代替存在跨引擎歧义的字符集合，保持禁止空白和方括号的原有限制。
- 补充部署前的嵌套字符集合检查；对实际 MCP 公布的 138 个工具、347 个正则执行 JavaScript、RE2、Python 和 Rust 正则引擎回归。
- 保留 1.4.1 托管运行包的可信哈希，允许旧版用户更新及在安装记录丢失时恢复；外部修改仍会阻止覆盖。
- 40 项单元测试通过。配置与本地 MCP 检查不等于 DeepSeek 官方 API 会话通过；仍需在更新后重启客户端确认。
- 2026-10-10 收到 DeepSeek Harness 官方直连场景的修复成功反馈；撤下存在兼容问题的 1.4.0、1.4.1 Release 及对应标签，历史变更记录保留。
- 感谢 QQ 2608422753 这位好友参与测试，帮助发现并验证修复问题。

步骤及验证边界见 [兼容性修复说明](REA_COMPATIBILITY.md)。

## 1.4.1 · 2026-10-09（2026-10-10 已撤下）

- 修复 REA 工具参数正则兼容问题。空字符约束使用通用写法，路径规范与保留环境变量检查继续在服务端执行。
- 在部署前遍历全部工具的参数 Schema，阻止已知不兼容表达式写入客户端连接。
- 已安装旧运行包时显示“更新 REA”，更新后重启 AI 客户端。
- 增加“修复并开启技能”：安装记录缺失但存在本软件遗留连接时，验证运行文件与配置来源、保存快照，再恢复。保留其他插件；不覆盖外部条目或修改过的技能。
- 38 项自动测试与七种配置的真实 CLI/MCP 验收通过。DeepSeek 官方 API 的实际会话仍需用户重试，不能以本地 Schema 检查替代。

步骤及验证范围见 [1.4.1 兼容性修复说明](REA_COMPATIBILITY.md)。

## 1.4.0 · 2026-10-09（2026-10-10 已撤下）

- 增加 REA 统一分析技能，内置技能由 53 项增至 54 项，保留 50 项扩展技能。
- 内置 REA 6.1.0、Node 24.19.0、npm 和配套依赖，首次注入无需联网安装。
- 开启任意方案时自动准备、校验、测试 REA CLI/MCP，并写入七种客户端连接配置。
- 增加准备进度和旧用户“启用 REA”入口。重启 AI 客户端后可直接说“使用技能”，由 AI 按任务选取技能。
- 使用持久数据目录运行 REA；关闭技能库窗口后，客户端仍能启动服务。
- 配置写入前备份，保留已有模型、认证、其他 MCP 和用户修改；支持失败回滚与撤销。
- 完成 33 项自动测试、七种配置隔离验收、最终 EXE 界面验收及真实 CLI/MCP 测试。安装后的实际 Codex 会话连接已确认。

验证范围、依赖条件与证据见 [REA 集成与验收](REA_INTEGRATION.md)。该版本发布包已于 2026-10-10 撤下，本地归档保留。
