# ai技能库 v1.3.2

**开发方式：AI 开发。**

Windows x64 桌面版本，双击运行，无需安装 Python。

## 功能

- 53 项内置技能、50 项扩展技能，支持七种 AI 客户端。
- 技能安装、切换、本地导入、自动备份、检查与撤销。
- 自定义图标、浅色与深色主题，页面和技能正文均可滚动。
- 约 7 秒的静音启动动画，无跳过按钮；动画铺满软件窗口，期间隐藏顶部标题栏，结束后恢复窗口按钮。
- 无账户、订阅或反馈页面，无需连接原服务器。

## 下载

| 文件 | 用途 |
| --- | --- |
| `AISkillLibrary-1.3.2-windows-x64.zip` | 推荐下载，包含程序与使用说明 |
| `AISkillLibrary-1.3.2-windows-x64.exe` | 可直接运行的单文件程序 |
| `AISkillLibrary-1.3.2-source.zip` | 可构建的源码快照 |
| `AISkillLibrary-1.3.2-skills-53.zip` | 53 项技能及目录入口，供独立查看或手动安装 |
| `AISkillLibrary-1.3.2-skills-extra-50.zip` | 50 项扩展技能及目录入口 |
| `SHA256SUMS.txt` | 发布附件 SHA-256 校验值 |

运行需要 Windows x64 与 WebView2 Runtime。完整程序已经包含技能，无需另外下载技能 ZIP。
独立技能包每个 `skills/<名称>/` 是一个技能；软件导入一次选择其中一个技能目录，而不是整个集合 ZIP。
