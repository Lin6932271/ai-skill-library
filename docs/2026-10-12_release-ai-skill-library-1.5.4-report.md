# ai技能库 1.5.4 版本说明与验收报告

报告日期：2026-10-12。适用平台：Windows x64。程序版本：1.5.4。

## 版本概述

ai技能库用于管理 AI 客户端技能，提供安装、切换、导入、备份、完整性检查和撤销。本版将原版与精品作为两套独立方案，并简化注入控制台的状态文字。

支持 Codex、Claude、DeepSeek Harness、Hermes、ZCode、WorkBuddy 国内版和 WorkBuddy 国际版，共 7 种客户端配置。

## 方案与开关

| 控件或方案 | 行为 |
| --- | --- |
| 上方方案开关关闭 | 选择原版技能 |
| 上方方案开关开启 | 选择精品技能 |
| 下方技能开关开启 | 安装当前选择的方案并准备 REA |
| 下方技能开关关闭 | 撤销程序管理的技能与该客户端 REA 连接 |
| 尚未安装时切换方案 | 只保存选择，等待用户开启技能 |
| 已安装时切换方案 | 先检查冲突、备份，再替换当前方案 |

每个客户端独立保存原版／精品选择，刷新、重启和撤销后保留选择。发现外部修改时，保留原文件与安装记录并提示冲突。旧版安装可通过“更新当前方案”更新，无需先撤销。

| 方案 | 目录数量 | 含可用正文的数量 |
| --- | ---: | ---: |
| 原版 | 49 | 49 |
| 精品 | 161 | 147 |

目录条目数量与可用正文数量分开核对。没有正文的项目不能预览或安装，部署时不会生成空白技能。共用 REA 组件不计入方案数量。

## 1.5.4 的界面变化

注入控制台顶部及客户端卡片清理正文获取状态提示，只展示当前方案与方案数量。技能库页面继续提供方案筛选，并明确标识不可用项目。安装、检查、备份、冲突保护和撤销流程沿用现有逻辑。

## 使用与升级

1. 运行 Windows EXE，确认客户端配置目录。
2. 选择上方开关：关闭原版，开启精品。
3. 首次使用时开启下方技能开关；已有安装需要升级时点击“更新当前方案”。
4. 等待准备和检查完成，完全退出并重新打开 AI 客户端，在新会话确认技能读取。

REA 6.1.0 与 Node 24.19.0 已内置。首次释放、完整性检查与独立启动测试可能需要数分钟；后续使用持久数据目录，不要求技能库窗口一直打开。

写入前自动备份，撤销只处理程序管理的内容。用户自己的文件或配置修改会保留，出现冲突时应先查看提示和备份。
