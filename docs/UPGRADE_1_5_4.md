# ai技能库 1.5.4 升级说明

上方开关关闭为原版技能，开启为精品技能；下方开关负责安装和撤销。各客户端独立保存选择。

本版整合两套独立方案，并清理控制台的正文获取状态提示。原版 49 项全部可用，精品目录 161 项，其中 147 项包含可用正文；没有正文的项目不能安装。

## 升级步骤

1. 从 [1.5.4 发布页面](https://github.com/Lin6932271/ai-skill-library/releases/tag/v1.5.4)下载 EXE，或解压便携 ZIP 运行 `ai技能库.exe`。
2. 确认配置目录及当前原版／精品选择。启动新版不会自动改写已有安装。
3. 需要更新已安装内容时，点击“更新当前方案”，等待备份和检查完成。需要安装时开启下方技能开关。
4. 点击“检查”，完全退出并重新打开对应 AI 客户端，在新会话确认读取。

首次准备 REA 可能需要数分钟。遇到配置冲突时按提示检查文件与备份，保留自己的修改。

## 交付与验证

提供 EXE、便携包、源码、原版与精品技能集合、版本报告、验证证据及 SHA256SUMS.txt。日常使用直接运行 EXE 即可。

54 项自动测试、最终 EXE 的 280 个资源核对及核心编译模块比较通过。原版与精品控制台的 7 个方案开关显示正常，控制台不显示正文获取状态提示；实际桌面窗口已确认运行 1.5.4。

文件检查通过与实际 AI 会话读取分别确认。内置 REA 不代表所有分析引擎已安装，专项工具和附件需在使用环境核对。详见[版本说明与验收报告](2026-10-12_release-ai-skill-library-1.5.4-report.md)。
