# 无线网络安全

> 本地重建版：原索引名称已恢复，以下正文重新编写；不是原云端原文。

## 何时使用

分析自有无线网络的配置、认证、流量和覆盖问题。

## 执行要点

- 确定自有 SSID、设备和测试范围，记录频道、加密与认证模式。
- 区分射频干扰、连接故障与认证问题，用配置和抓包互证。
- 在隔离测试网络验证认证与访问隔离，不干扰周边网络或截取他人内容。
- 输出配置修复与覆盖建议，复测合法连接和隔离条件。

## 交付与验收

无线配置、抓包证据、连接诊断与修复复测。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
