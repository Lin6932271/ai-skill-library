# 通用逆向分析

> 本地重建版：原索引名称已恢复，以下正文重新编写；不是原云端原文。

## 何时使用

分析 PE/ELF、壳、混淆、加载器或配置恢复。

## 执行要点

- 记录格式、架构、节区、导入和样本哈希，先锁定问题对应的路径。
- 将字符串/资源、调用引用与控制流互证，识别库代码和动态载荷。
- 恢复配置或载荷时解释格式、压缩/编码与校验，不执行未确认内容。
- 用受控副本验证关键结论，区分可读代码、重构实现和原始源码。

## 交付与验收

二进制画像、关键路径、提取器与证据化结论。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
