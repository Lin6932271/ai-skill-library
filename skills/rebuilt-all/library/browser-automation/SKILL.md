# 浏览器自动化

> 本地重建版：原索引名称已恢复，以下正文重新编写；不是原云端原文。

## 何时使用

在网页中执行可验证的导航、表单与交互任务。

## 执行要点

- 确定页面、登录状态和目标结果，使用稳定标签、角色或明确选择器。
- 每个改变状态的动作后等待实际页面条件，避免固定长等待与盲目重试。
- 凭据由用户或现有会话提供；提交、发送或购买等动作遵循当前授权。
- 记录截图、页面结果与失败原因，区分点击成功和业务提交成功。

## 交付与验收

可执行自动化、稳定等待、结果证据与恢复方式。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
