# 硬件接口分析

> 本地重建版：原索引名称已恢复，以下正文重新编写；不是原云端原文。

## 何时使用

分析自有硬件的 UART/JTAG、启动与调试接口。

## 执行要点

- 记录型号、接口、电压与接线证据，先测量后连接。
- 区分日志输出、调试接口、烧录接口和供电引脚，保留串口参数。
- 在具备恢复条件的测试设备验证读取路径，不贸然擦写或改变熔丝。
- 结合固件与启动过程解释接口权限，记录设备状态和复现限制。

## 交付与验收

接口/接线图、读取证据、启动流程与恢复条件。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
