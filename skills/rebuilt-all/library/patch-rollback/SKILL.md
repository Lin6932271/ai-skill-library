# 补丁与回滚

> 本地重建版：原索引名称已恢复，以下正文重新编写；不是原云端原文。

## 何时使用

以可恢复方式修改已有文件、配置或本地制品。

## 执行要点

- 保存原始字节和哈希，列出本次拥有的文件与管理段。
- 写入采用暂存和原子替换，失败时只回滚本次成功写入的内容。
- 撤销前比较已写哈希；外部修改保留并报告冲突，避免恢复整个旧文件覆盖用户新内容。
- 验证多次执行、部分失败和恢复路径，保留可人工处理的备份。

## 交付与验收

补丁差异、原始备份、冲突记录和回滚验证。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
