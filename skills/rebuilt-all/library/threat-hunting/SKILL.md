# 威胁狩猎与检测

> 本地重建版：原索引名称已恢复，以下正文重新编写；不是原云端原文。

## 何时使用

将行为假设转为日志查询、检测规则和可验证线索。

## 执行要点

- 明确威胁假设和必要数据源，先验证日志字段与覆盖率。
- 按进程、身份、时间与主机关联事件，使用多证据条件减少误报。
- 对检测规则记录良性对照、漏报条件和性能影响。
- 将命中视为待调查线索，保留查询时间范围与可复现过滤条件。

## 交付与验收

狩猎假设、查询逻辑、证据关联和规则验证。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
