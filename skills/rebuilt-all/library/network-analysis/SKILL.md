# 网络流量分析

> 本地重建版：原索引名称已恢复，以下正文重新编写；不是原云端原文。

## 何时使用

分析 PCAP、协议会话、异常请求或连接故障。

## 执行要点

- 保留原抓包时间、接口和过滤条件，记录丢包与截断限制。
- 按五元组和会话重组，先区分 DNS、TCP/TLS 建连、HTTP 和业务阶段。
- 结合序列号、重传、状态码、延迟和应用日志判断故障位置，不以端口通断代替业务成功。
- 导出最小证据流和时间轴，对个人数据、密钥和会话内容保持必要的脱敏。

## 交付与验收

会话时间线、协议字段、故障证据和可复现过滤条件。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
