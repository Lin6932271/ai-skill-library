# 移动端逆向

> 本地重建版：原索引名称已恢复，以下正文重新编写；不是原云端原文。

## 何时使用

分析 iOS/IPA 或跨平台移动客户端、存储与运行时边界。

## 执行要点

- 确认平台、包结构、签名和调试能力，区分可静态读取与需设备验证的内容。
- 建立入口、敏感数据、网络调用和 native 桥接图，标注系统 API 与应用代码。
- 优先在隔离设备或模拟器验证假设；若真机条件不满足，保留静态结论范围。
- 导出修改前后差异，说明重新签名、系统版本和设备环境对复现的影响。

## 交付与验收

包结构、关键调用链、设备适用范围和复现记录。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
