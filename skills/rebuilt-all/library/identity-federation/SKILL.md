# 身份联邦审查

> 本地重建版：原索引名称已恢复，以下正文重新编写；不是原云端原文。

## 何时使用

审查 SAML/OIDC 的验证、租户绑定和会话边界。

## 执行要点

- 画出 IdP、服务方、回调与会话流程，记录 issuer/audience 和租户绑定。
- 检查签名/密钥来源、状态参数、重放、过期和账户关联逻辑。
- 用测试身份验证错误租户、错误受众与失效会话，保留脱敏证据。
- 给出验证顺序与回归条件，确保修复不破坏正常登录和退出。

## 交付与验收

认证流程图、验证缺口、脱敏样本和回归矩阵。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
