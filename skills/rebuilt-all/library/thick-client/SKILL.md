# 桌面客户端分析

## 何时使用

检查桌面应用、本地存储、更新与进程间信任边界。

## 执行要点

- 识别程序框架、嵌入资源、辅助进程和配置位置。
- 区分界面状态、本地门禁与服务器控制，记录各层数据来源。
- 检查本地 IPC、文件权限、路径、更新完整性和凭据存储。
- 验证使用隔离配置与副本，交付源代码重建范围和不能恢复的组件。

## 交付与验收

程序结构、IPC/存储边界、复现证据与重建限制。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
