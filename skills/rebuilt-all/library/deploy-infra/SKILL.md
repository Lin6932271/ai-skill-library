# 部署与基础设施

> 本地重建版：原索引名称已恢复，以下正文重新编写；不是原云端原文。

## 何时使用

规划可回滚的部署、配置变更与基础设施迁移。

## 执行要点

- 记录当前拓扑、依赖、数据与网络约束，先形成可审查的变更。
- 检查配置/凭据边界、健康检查和数据迁移前置条件。
- 部署后验证实际请求路径与运行配置，不能只凭服务进程运行判成功。
- 准备回滚触发条件、数据兼容性和恢复步骤，保持用户明确的 IP/接口约束。

## 交付与验收

变更计划、配置差异、运行验证与回滚条件。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
