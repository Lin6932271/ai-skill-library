# 协议逆向

## 何时使用

从实现或样本流量还原消息帧、字段和状态机。

## 执行要点

- 收集相同操作的多份样本，关联时间、方向、连接状态与业务动作。
- 区分帧长度、字段编码、压缩、加密和校验，记录每个假设的验证样本。
- 建立解析器并对截断、未知字段、重传与版本变化做回归。
- 协议重放限定测试目标；交付状态机与格式文档，不把猜出的字段名写成确认事实。

## 交付与验收

帧格式、状态机、解析器测试和字段置信度。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
