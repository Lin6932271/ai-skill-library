# 容器运行时诊断

## 何时使用

排查 Docker/containerd 的构建、启动、资源与网络问题。

## 执行要点

- 区分镜像构建、容器进程、卷、网络与宿主机层，记录实际版本和状态。
- 关联日志、退出码、健康状态和资源限制，定位最小可复现条件。
- 保护持久卷和配置，调整前备份；不以重建容器代替根因诊断。
- 使用实际服务请求复测，记录配置与运行实例之间的对应关系。

## 交付与验收

分层诊断、最小修复、数据保护和业务验证。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
