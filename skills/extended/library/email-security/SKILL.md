# 邮件安全

## 何时使用

分析邮件头、认证配置、样本附件和异常投递。

## 执行要点

- 保留原邮件与时间信息，区分显示发件人、信封发件人和投递链。
- 关联 SPF/DKIM/DMARC 结果、跳转链接与附件哈希，核对每个信任边界。
- 附件在隔离环境静态分析，测试演练仅用自有账户和合成邮件。
- 交付判断证据、配置修复和误报条件，不凭主题或外观断定真实性。

## 交付与验收

邮件头分析、样本证据、认证配置与检测建议。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
