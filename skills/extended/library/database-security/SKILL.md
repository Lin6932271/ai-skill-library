# 数据库安全

## 何时使用

检查数据库账户、权限、查询与备份的数据边界。

## 执行要点

- 列出实例、角色、服务账户、访问路径与数据敏感度。
- 核对最小权限、跨库/跨租户访问、动态 SQL 与参数处理。
- 用测试数据验证访问边界和审计记录，不使用生产敏感数据做演示。
- 修复建议同时覆盖账户、查询、备份和恢复流程，并复测业务兼容性。

## 交付与验收

权限矩阵、查询/配置发现、修复与恢复验证。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
