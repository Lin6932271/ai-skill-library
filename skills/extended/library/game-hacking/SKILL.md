# 游戏程序分析与离线调试

## 何时使用

分析自有或可调试游戏的内存、引擎逻辑和离线修改。

## 执行要点

- 先确认离线/测试环境、引擎、架构和版本，记录存档与程序备份。
- 从可观察行为映射状态、对象生命周期和函数调用，区分本地显示值与服务器状态。
- 每次只改变一个变量，记录地址稳定性、版本差异和重启后行为。
- 交付可撤销的测试改动与验证记录；涉及联网环境时保持测试边界，不实现隐蔽对抗。

## 交付与验收

对象/状态映射、离线复现、版本适用范围与撤销步骤。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
