# 软件供应链审查

## 何时使用

分析依赖来源、构建输入、SBOM 与制品完整性。

## 执行要点

- 区分源码依赖、构建工具和运行依赖，记录锁文件、来源和版本。
- 核对实际制品中的组件与声明，关注可达代码路径而非只罗列漏洞编号。
- 检查包来源、构建凭据边界、校验和签名、缓存与更新机制。
- 给出最小升级或替换方案，并验证兼容性与可复现构建。

## 交付与验收

依赖/制品对应表、可达风险、修复计划和构建验证。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
