# mitmproxy HTTP/TLS/WebSocket 可编程代理 技能卡

## 基本信息

- **中文名称**：mitmproxy HTTP/TLS/WebSocket 可编程代理
- **来源仓库**：[mitmproxy/mitmproxy](https://github.com/mitmproxy/mitmproxy)

## 原说明列出的能力（需核对）

1. 捕获、查看、过滤和保存 HTTP/HTTPS/WebSocket 流量
2. 用 addon 脚本对请求/响应做观测、标注和测试性变换
3. 提供 CLI、Web UI、流文件和回放接口

## 不能替代的边界

- 不能替代服务端状态真值、加密协议密钥、游戏内存/函数分析或稳定业务成功证据；TLS 证书安装、协议差异和版本变化必须单独核对。

## 输入与输出合同

```text
输入：监听地址/端口、客户端证书信任、过滤规则、流文件和 addon。
输出：流事件、请求/响应头体、WebSocket 帧、保存的 flow 文件和 addon 日志。
失败：证书不信任、连接升级失败、HTTP/2/WebSocket 不兼容或流损坏时保留原始错误，不伪造成功。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```

## 接入原则

1. 核对实际源码版本和参考提交，先做最小、可撤销、可回放的接入。
2. 任何地址、线程、设备、模型、资源或协议输入都必须记录来源、版本和后置状态。
3. 工具输出是候选或观测，必须与项目专项规则、状态机和真实成功证据交叉验证。
4. 失败时保留原始错误和现场证据，不把命令退出码、识别命中或 Hook 安装当作业务成功。
5. 可与 Perfetto、Mumu/ADB、UI 自动化组成证据链；网络观察不替代 IL2CPP 或对局状态机。
