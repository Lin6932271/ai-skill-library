## 原说明列出的能力（需核对）

1. 将机器码解码为指令、操作数、地址和架构特征
2. 支持多架构、语法选项、跳转/寄存器细节和批量反汇编
3. 可嵌入静态分析、签名定位和指令级验证工具

## 不能替代的边界

- 不是完整反编译器、符号恢复器、IL2CPP 解析器或 Hook 安装库；反汇编结果不能单独证明函数语义或偏移稳定。

## 输入与输出合同

```text
输入：目标模块字节、起始地址、架构/模式、字节长度和语法选项。
输出：指令列表、地址、助记符、操作数、解码错误和分析日志。
失败：架构模式错误、截断字节、非法指令或地址映射不一致时返回失败并保留输入版本。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```

## 接入原则

1. 核对实际源码版本和参考提交，先做最小、可撤销、可回放的接入。
2. 任何地址、线程、设备、模型、资源或协议输入都必须记录来源、版本和后置状态。
3. 工具输出是候选或观测，必须与项目专项规则、状态机和真实成功证据交叉验证。
4. 失败时保留原始错误和现场证据，不把命令退出码、识别命中或 Hook 安装当作业务成功。
5. 可为 Ghidra、Dobby、ShadowHook 和 IL2CPP 分析提供指令证据；不替代它们的工程接入与线程安全门禁。

## 与 Codex 项目路由的边界

- `l-gameassist`：负责游戏目标、进程/设备连接和现场任务编排；本技能只提供本卡标注的工具能力，不能扩展为未登记的内存、Hook、协议或输入能力。
- `l-reverse`：负责逆向/静态或运行时证据路由；本技能的输出必须按目标版本、模块、ABI 和现场回读复核，不能把候选分析直接当作成功结论。
- `build-release`：负责构建、依赖、配置、部署、回滚和服务维护；本技能不替代发布门禁，未完成依赖、许可证、异常恢复和回滚检查时不得发布。
