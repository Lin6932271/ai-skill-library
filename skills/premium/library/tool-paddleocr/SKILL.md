# PaddleOCR OCR 与文档视觉工具链 技能卡

## 基本信息

- **中文名称**：PaddleOCR OCR 与文档视觉工具链
- **来源仓库**：[PaddlePaddle/PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR)
- **上游参考分支**：`main`
- **参考提交（使用前核对）**：`2661c7c0ef5c613e8f93c6e93b2e052399f0f854`
- **许可证线索**：Apache-2.0（模型/第三方组件需按各自条款）；文件：`源码\LICENSE`

## 功能概览

1. 检测图像中的文本区域并识别字符、方向和置信度
2. 支持多语言、文档结构、版面和表格等扩展任务
3. 提供模型配置、推理 API、部署和批量处理脚本

## 适用范围

- 用于游戏 UI 文字、天赋/状态标签、结果页面和日志截图的文字识别。

## 不能替代的边界

- 不负责截图采集、点击输入、游戏内存/IL2CPP、策略决策或服务端成功判定；OCR 置信度低时不能当作事实。

## 输入与输出合同

```text
输入：裁剪图像、语言/模型配置、预处理参数、设备和推理后端。
输出：文本框、识别文本、方向、置信度、版面结构和推理日志。
失败：空帧、模型缺失、文字遮挡/动画、低置信度或推理超时需标记待确认并保存原图。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```
