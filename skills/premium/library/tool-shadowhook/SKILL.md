# ShadowHook Android Inline Hook 库 技能卡

## 基本信息

- **中文名称**：ShadowHook Android Inline Hook 库
- **来源仓库**：[bytedance/android-inline-hook](https://github.com/bytedance/android-inline-hook)
- **上游参考分支**：`main`
- **参考提交（使用前核对）**：`593f491be68799f03ee3bab71ce5908846437147`
- **许可证线索**：MIT；文件：`源码\LICENSE`

## 功能概览

1. 在 Android native 进程中安装 inline hook/trampoline
2. 处理符号、地址、共享库和递归/线程等 Hook 常见问题
3. 提供 Java/Gradle 工程与 C/C++ API 接入路径

## 适用范围

- 用于 Android native 函数观测、替换和调用链采集，尤其是 ARM/ARM64 目标。

## 不能替代的边界

- 不提供函数定位、IL2CPP 类型恢复、ABI 自动推断、游戏线程调度、协议或生命周期守护；Hook 成功不等于动作/状态成功。

## 输入与输出合同

```text
输入：目标 so/符号/地址、Hook 函数签名、ABI、线程时机、安装和撤销配置。
输出：Hook/恢复状态、trampoline、调用事件、错误码和性能数据。
失败：地址不可执行、指令重定位失败、ABI/版本不符、并发卸载或权限错误时必须回滚。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```

## 接入原则

1. 核对实际源码版本与说明中的参考提交后，先做最小、可撤销、可回放的接入。
2. 任何地址、线程、设备、模型、资源或协议输入都必须记录来源、版本和后置状态。
3. 工具输出是候选或观测，必须与项目专项规则、状态机和真实成功证据交叉验证。
4. 失败时保留原始错误和现场证据，不把命令退出码、识别命中或 Hook 安装当作业务成功。
5. 与 Dobby 是替代型 inline Hook 方案；可与 IL2CPP 运行时桥接、libffi、Capstone 配合但需单独门禁。
