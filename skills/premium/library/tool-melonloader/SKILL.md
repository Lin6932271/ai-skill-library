# MelonLoader Unity Mono/IL2CPP 模组加载器 技能卡

## 基本信息

- **中文名称**：MelonLoader Unity Mono/IL2CPP 模组加载器
- **来源仓库**：[LavaGang/MelonLoader](https://github.com/LavaGang/MelonLoader)

## 功能概览

1. 在 Unity 启动阶段装载托管/原生模组和依赖
2. 提供模组生命周期、日志、配置、版本兼容和基础 API
3. 适合将运行时观测或 UI 扩展作为独立模组部署

## 适用范围

- 用于 Unity 项目的模组宿主、启动顺序管理和运行日志接入。

## 不能替代的边界

- 不等同于 IL2CPP 元数据恢复或通用 Hook；不保证目标版本兼容、不负责 ABI/线程调度、协议、守护或业务成功。

## 输入与输出合同

```text
输入：Unity 版本/架构、安装目录、模组程序集/原生库、依赖和配置。
输出：加载日志、模组生命周期事件、配置快照、错误堆栈和运行状态。
失败：Bootstrap、依赖或模组初始化失败时必须阻止半初始化状态并保留日志/版本信息。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```
