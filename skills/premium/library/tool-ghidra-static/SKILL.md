# Ghidra 静态逆向分析框架 技能卡

## 基本信息

- **中文名称**：Ghidra 静态逆向分析框架
- **来源仓库**：[NationalSecurityAgency/ghidra](https://github.com/NationalSecurityAgency/ghidra)
- **上游参考分支**：`master`（本地固定提交为 detached HEAD）
- **参考提交（需核对）**：`2035b8153afaf7ce2edde24a2c80b62bbcf5127f`
- **许可证线索**：Apache-2.0；另含 NOTICE 和组件许可；文件：`源码\LICENSE; 源码\NOTICE`

## 原说明列出的能力（需核对）

1. 导入 PE、ELF、Mach-O 等文件并进行反汇编与反编译
2. 构建函数、交叉引用、控制流图、数据类型和符号分析
3. 通过 Java/Python 脚本批量标注、导出和重复分析

## 不能替代的边界

- 静态推断不等于运行时地址或函数语义；不提供进程注入、实时内存读取、线程调度、网络回执或 AI 决策。

## 输入与输出合同

```text
输入：目标二进制/符号文件、处理器语言、加载基址、分析选项和脚本。
输出：函数/符号/交叉引用、反编译文本、控制流图、脚本报告和工程数据库。
失败：文件损坏、架构选择错误、符号缺失或自动分析不完整时需标注不确定性，不得伪造结论。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```

## 接入原则

1. 核对实际源码版本和参考提交，先做最小、可撤销、可回放的接入。
2. 任何地址、线程、设备、模型、资源或协议输入都必须记录来源、版本和后置状态。
3. 工具输出是候选或观测，必须与项目专项规则、状态机和真实成功证据交叉验证。
4. 失败时保留原始错误和现场证据，不把命令退出码、识别命中或 Hook 安装当作业务成功。
5. 可与 Il2CppDumper/Cpp2IL、Capstone、PointerScan 互补；输出只是候选，接入由运行时门禁决定。

## 与 Codex 项目路由的边界

- `l-gameassist`：负责游戏目标、进程/设备连接和现场任务编排；本技能只提供本卡标注的工具能力，不能扩展为未登记的内存、Hook、协议或输入能力。
- `l-reverse`：负责逆向/静态或运行时证据路由；本技能的输出必须按目标版本、模块、ABI 和现场回读复核，不能把候选分析直接当作成功结论。
- `build-release`：负责构建、依赖、配置、部署、回滚和服务维护；本技能不替代发布门禁，未完成依赖、许可证、异常恢复和回滚检查时不得发布。

## 接入前专项检查

- 核对处理器语言、加载基址、符号、Java/脚本环境及分析选项，记录自动分析不完整范围。
- 静态函数、交叉引用与类型是候选；用实际目标复核运行时地址和语义，保存可审查报告。
