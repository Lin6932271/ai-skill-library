# uiautomator2 Android UI 自动化 技能卡

## 基本信息

- **中文名称**：uiautomator2 Android UI 自动化
- **来源仓库**：[openatx/uiautomator2](https://github.com/openatx/uiautomator2)
- **上游参考分支**：`master`
- **参考提交（使用前核对）**：`b788548cf5a8e318ecbdd22461d47d19bf53b04c`
- **许可证线索**：MIT；文件：`源码\LICENSE`

## 功能概览

1. 按 resource-id、文本、类名、XPath 等选择器查找控件
2. 执行点击、滑动、输入、截图、应用管理和设备信息读取
3. 通过 HTTP 服务与 Python 客户端分离，适合多设备编排

## 适用范围

- 用于结构化 UI 控件可访问的 Android 应用自动化、状态读取和输入回执。

## 不能替代的边界

- 依赖 UI 暴露和服务存活；不解析游戏渲染纹理、内存/IL2CPP、native Hook、网络协议或服务端状态。控件调用回执不等于游戏状态改变。

## 输入与输出合同

```text
输入：ADB serial/HTTP endpoint、选择器、动作、超时、应用包名和设备配置。
输出：控件属性、动作回执、截图、应用状态、HTTP/ADB 日志。
失败：服务未启动、选择器无结果、设备断连、HTTP 超时或应用切换时保存现场并停止旧会话。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```

3. 工具输出是候选或观测，必须与项目专项规则、状态机和真实成功证据交叉验证。

5. 与 Airtest 是结构化 UI 与图像 UI 的互补方案；可由 MuMu API/scrcpy 提供设备后端。
