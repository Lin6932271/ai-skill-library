# ONNX Runtime 跨平台推理运行时 技能卡

## 基本信息

- **中文名称**：ONNX Runtime 跨平台推理运行时
- **来源仓库**：[microsoft/onnxruntime](https://github.com/microsoft/onnxruntime)
- **上游参考分支**：`main`
- **参考提交（使用前核对）**：`d46218a8ca85da83542cbf2625bfcc84cddca5b8`
- **许可证线索**：MIT（执行提供程序和第三方组件另有条款）；文件：`源码\LICENSE`

## 功能概览

1. 加载 ONNX 模型并执行图推理、批处理和张量 I/O
2. 通过不同 Execution Provider 适配 CPU、CUDA、DirectML 等后端
3. 提供 C/C++、Python、C#/Java 等 API 以及性能配置

## 适用范围

- 用于目标检测、状态分类、动作策略的模型推理层；模型输入输出可纳入项目状态机。

## 不能替代的边界

- 不训练模型、不提供 OCR/视觉标注、不读取游戏内存、不执行输入动作，也不证明模型决策正确或成功率百分百。

## 输入与输出合同

```text
输入：固定 ONNX 模型、张量形状/类型、预处理参数、Execution Provider 和会话选项。
输出：推理张量、耗时、执行提供程序信息、错误和模型元数据。
失败：模型不兼容、形状/类型错误、后端不可用或超时需返回失败并记录输入哈希。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```

## 接入原则

1. 核对实际源码版本与说明中的参考提交后，先做最小、可撤销、可回放的接入。
2. 任何地址、线程、设备、模型、资源或协议输入都必须记录来源、版本和后置状态。
3. 工具输出是候选或观测，必须与项目专项规则、状态机和真实成功证据交叉验证。
4. 失败时保留原始错误和现场证据，不把命令退出码、识别命中或 Hook 安装当作业务成功。
5. 可与 OpenCV/PaddleOCR/MaaFramework 组成视觉决策链；不替代 UI 或游戏线程执行层。
