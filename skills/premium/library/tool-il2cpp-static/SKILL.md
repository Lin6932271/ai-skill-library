# IL2CPP 静态分析（Il2CppDumper） 技能卡

## 基本信息

- **中文名称**：IL2CPP 静态分析（Il2CppDumper）
- **来源仓库**：[Perfare/Il2CppDumper](https://github.com/Perfare/Il2CppDumper)
- **上游参考分支**：`master`（本地固定提交为 detached HEAD）
- **参考提交（使用前核对）**：`4741d46ba9cd6159c5d853eb9d6fc48b4bfa2b1a`
- **许可证线索**：MIT；文件：`源码\LICENSE`

## 功能概览

1. 读取 global-metadata.dat 与 IL2CPP 二进制，恢复类型/方法/字段等元数据
2. 生成脚本、结构体头文件和地址映射，辅助静态分析
3. 支持 Android 内存转储的 libil2cpp.so 解析及部分简单保护场景

## 适用范围

- 用于建立 IL2CPP 类、方法、字段、结构体和静态地址候选，作为运行时调用前的元数据证据。

## 不能替代的边界

- 不保证恢复原始 C# 逻辑、不负责运行时 Hook、线程调度、ABI 适配、指针链稳定或业务成功；静态 RVA 需按版本和模块基址复核。

## 输入与输出合同

```text
输入：目标版本的 IL2CPP 二进制、global-metadata.dat（或受支持转储）、架构和输出目录。
输出：恢复 DLL/脚本/头文件、元数据表、方法/字段地址候选和解析日志。
失败：元数据版本不支持、加密/损坏、二进制不匹配或模式判断错误时停止并记录原始文件哈希。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```
