# IL2CPP 运行时桥接（frida-il2cpp-bridge） 技能卡

## 基本信息

- **中文名称**：IL2CPP 运行时桥接（frida-il2cpp-bridge）
- **来源仓库**：[vfsfitvnm/frida-il2cpp-bridge](https://github.com/vfsfitvnm/frida-il2cpp-bridge)
- **上游参考分支**：`master`（本地固定提交为 detached HEAD）
- **参考提交（使用前核对）**：`6dbef2576ccf207245a211f0b8126addb2abc9f4`
- **许可证线索**：MIT；文件：`源码\LICENSE`

## 功能概览

1. 运行时枚举程序集、类、字段和方法并生成 dump
2. 跟踪、拦截、替换方法调用，读取/设置托管对象成员
3. 通过 TypeScript/Frida 脚本编排运行时观察与调用

## 适用范围

- 用于 IL2CPP 运行时探针、方法签名确认、调用链观测和小范围运行时验证。

## 不能替代的边界

- 不自动解决线程亲和、JNI/NativeBridge、ARM64/x86_64 ABI、生命周期、服务端回执或成功证明；运行时替换具有版本和线程风险。

## 输入与输出合同

```text
输入：Frida 目标进程、脚本、类/方法选择器、参数类型、线程/时机约束和版本信息。
输出：类/方法 dump、调用 trace、拦截回调、返回值/异常和脚本日志。
失败：进程未就绪、IL2CPP 初始化未完成、符号/签名不匹配、脚本异常或线程错误时需停止并保存现场。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```

## 接入原则

1. 核对实际源码版本与说明中的参考提交后，先做最小、可撤销、可回放的接入。
2. 任何地址、线程、设备、模型、资源或协议输入都必须记录来源、版本和后置状态。
3. 工具输出是候选或观测，必须与项目专项规则、状态机和真实成功证据交叉验证。
4. 失败时保留原始错误和现场证据，不把命令退出码、识别命中或 Hook 安装当作业务成功。
5. 与 Il2CppDumper/Cpp2IL 提供静态对照，与 libffi、Dobby/ShadowHook 提供底层补充；桥接本身不等于完整功能实现。

## 与 Codex 项目路由的边界

- `l-gameassist`：负责游戏目标、进程/设备连接和现场任务编排；本技能只提供本卡标注的工具能力，不能扩展为未登记的内存、Hook、协议或输入能力。
- `l-reverse`：负责逆向/静态或运行时证据路由；本技能的输出必须按目标版本、模块、ABI 和现场回读复核，不能把候选分析直接当作成功结论。
- `l-dev`：负责构建、依赖、配置、部署、回滚和服务维护；本技能不替代发布门禁，未完成依赖、许可证、异常恢复和回滚检查时不得发布。
